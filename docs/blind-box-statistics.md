# 盲盒统计

启用 `BlindBoxStat: true` 后，直接发送以下弹幕即可查询，不需要 @ 机器人。

| 查询范围 | 支持的说法 |
| --- | --- |
| 今天 | `今日盲盒`、`今天盲盒`、`当日盲盒`、`当天盲盒` |
| 昨天／前天 | `昨日盲盒`、`昨天盲盒`、`前日盲盒`、`前天盲盒` |
| 本周 | `本周盲盒`、`这周盲盒`、`本星期盲盒`、`这个星期盲盒` |
| 上周 | `上周盲盒`、`上星期盲盒`、`上个星期盲盒` |
| 本月 | `本月盲盒`、`这个月盲盒`、`当月盲盒`、`盲盒` |
| 上月 | `上月盲盒`、`上个月盲盒` |
| 当年指定月份 | `1月盲盒`～`12月盲盒`、`一月盲盒`～`十二月盲盒` |
| 全部历史 | `盲盒统计` |

按日、周、月的命令也支持追加“统计”，例如 `今日盲盒统计`、`十月盲盒统计`。仅完整匹配命令，不会把“今天盲盒真好玩”等聊天当成查询。

统计使用北京时间（Asia/Shanghai）：一天从 00:00 开始，一周从周一 00:00 到下周一 00:00，一个月从 1 日到下个月 1 日，均包含起点、不包含终点。周统计可跨月、跨年。指定月份默认当年；例如 `十月盲盒` 与 `10月盲盒` 相同。

普通观众查询自己在当前直播间的数据；主播查询当前直播间所有人的数据。“全部历史”也遵循这个范围，汇总机器人数据库中所有年份的已记录数据，不会补采安装机器人之前的历史礼物。

结果包含开盒数量和总盈亏。例如 `本周数量14个，盈亏+0.50元`。盈亏按每个盲盒开出礼物的价值减去盲盒价格，再乘数量计算。没有记录时回复 `本周暂无相关记录`，有记录但盈亏为零时显示 `盈亏+0.00元`。现有按年、月、日保存的数据可直接查询，不需要迁移数据库。
